# Pleo Connector — Ideal Onboarding Guide

## Prerequisites
1. Pleo administrator or developer account.
2. An active API token generated from Pleo Web Settings > Integrations > API Access.

## Step-by-Step Connection Flow
1. Open the Pleo Connector panel in Imperal Cloud.
2. In the connection form, enter a friendly label (e.g. `Main Pleo Account`).
3. Paste your Pleo API Bearer Token into the `API Key / Token` field.
4. Click **Connect Pleo**.
5. The system performs a harmless verification request to `GET /me`.
6. Upon successful verification, your account is saved and immediately available for chat automation and workflows.
